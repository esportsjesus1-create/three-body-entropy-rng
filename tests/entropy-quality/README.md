# Entropy Quality Assurance Tests

This directory contains statistical tests to validate the quality of entropy generated by the three-body physics simulation. The tests implement a subset of the NIST SP 800-22 randomness test suite along with additional statistical measures to ensure the entropy is suitable for cryptographic and gaming applications.

## Overview

The entropy quality tests verify that the three-body gravitational simulation produces high-quality random values by analyzing statistical properties of the generated entropy. These tests are critical for ensuring provably fair gaming outcomes.

## Test Suite Components

### NIST Statistical Tests (`utils/nist-tests.ts`)

The NIST tests implement standardized randomness validation based on NIST Special Publication 800-22:

**Frequency (Monobit) Test**: Tests whether the number of ones and zeros in a binary sequence are approximately equal, as expected for a truly random sequence. The test calculates the proportion of ones and uses the complementary error function to determine the p-value.

**Runs Test**: Analyzes the oscillation between zeros and ones in the sequence. A run is an uninterrupted sequence of identical bits. The test determines whether the number of runs is consistent with a random sequence.

**Chi-Square Test**: Tests whether the distribution of values is uniform across buckets. This verifies that entropy values don't cluster in certain ranges but are evenly distributed.

**Entropy Estimation**: Calculates the Shannon entropy of the data to measure the information content. Maximum entropy indicates maximum randomness.

### Main Test File (`entropy-quality.test.ts`)

The main test file orchestrates the statistical tests and includes:

- NIST randomness test suite execution with 1000+ samples
- Uniform distribution verification using chi-square tests
- Entropy estimation and validation
- Uniqueness verification (no duplicate hashes)
- Serial correlation tests for statistical independence
- Extended tests with 10000 samples for higher confidence

## Running the Tests

### Prerequisites

Install dependencies from the tests directory:

```bash
cd tests
npm install
```

### Run All Entropy Quality Tests

```bash
cd tests
npx vitest run entropy-quality/entropy-quality.test.ts
```

### Run with Verbose Output

```bash
cd tests
npx vitest run entropy-quality/entropy-quality.test.ts --reporter=verbose
```

### Run Specific Test Suites

```bash
# Run only NIST tests
npx vitest run entropy-quality/entropy-quality.test.ts --testNamePattern="NIST"

# Run only distribution tests
npx vitest run entropy-quality/entropy-quality.test.ts --testNamePattern="Distribution"

# Run extended tests (10000 samples)
npx vitest run entropy-quality/entropy-quality.test.ts --testNamePattern="Extended"
```

## Test Configuration

### Sample Sizes

- **Standard tests**: 1000 samples (approximately 3-5 minutes)
- **Extended tests**: 10000 samples (approximately 30-60 minutes)

### Significance Level

All tests use a significance level of α = 0.01 (99% confidence). A test passes if its p-value exceeds 0.01.

### Timeout Settings

- Standard tests: 5 minutes for sample generation
- Extended tests: 10 minutes for sample generation

## Interpreting Results

### P-Values

The p-value represents the probability of observing the test statistic (or more extreme) if the sequence were truly random:

- **p-value > 0.01**: Test passes (99% confidence)
- **p-value ≤ 0.01**: Test fails, indicating non-random behavior

### Entropy Ratio

The entropy ratio compares actual Shannon entropy to maximum possible entropy:

- **≥ 95%**: Excellent randomness
- **90-95%**: Acceptable randomness
- **< 90%**: Poor randomness, investigation needed

### Correlation Coefficients

Serial correlation should be close to zero for independent samples:

- **|r| < 0.1**: No significant correlation
- **|r| ≥ 0.1**: Potential correlation, investigate

## CI Integration

The entropy quality tests run automatically on all pull requests via GitHub Actions. See `.github/workflows/entropy-quality.yml` for the CI configuration.

### CI Behavior

- **On PRs**: Runs standard tests (1000 samples)
- **On main branch push**: Runs both standard and extended tests

### Failure Handling

If entropy quality tests fail in CI:

1. Check the test output for which specific test failed
2. Review the p-value and test statistic
3. Investigate recent changes to the physics simulation
4. Consider increasing sample size for borderline failures

## Technical Details

### Binary Conversion

Hex strings are converted to binary for bit-level tests:
```
hex "a" -> binary "1010"
hex "f" -> binary "1111"
```

### Chi-Square Calculation

The chi-square statistic is calculated as:
```
χ² = Σ (observed - expected)² / expected
```

### Shannon Entropy

Shannon entropy is calculated as:
```
H = -Σ p(x) * log₂(p(x))
```

where p(x) is the probability of symbol x.
